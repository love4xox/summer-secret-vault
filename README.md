# 🌸 여름 비밀 창고 (Summer Secret Vault)

> 스튜디오 지브리 감성의 생각 쪽지 및 아카이브 웹 애플리케이션

## ✨ 주요 기능
- **비밀의 꽃밭**: 생각 쪽지 남기기, 검색 및 태그 필터링, 지브리 포토 카드 아카이브 (16:9)
- **바다기차 창밖 뷰**: 저장된 쪽지 슬라이드 감상 및 앰비언트 사운드
- **약속 보관함**: 소중히 간직하고 싶은 다짐과 약속 모음
- **푸른 언덕길**: 쪽지 통계 현황 확인, JSON 데이터 백업 및 복원

## 🛠 Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Font**: Gowun Batang (Google Fonts)
- **Icons**: Lucide React
- **Audio**: Web Audio API
